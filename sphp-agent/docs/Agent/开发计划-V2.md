## 一、项目概述

**智愈先锋（SPHP）Agent 模块** — AI 驱动的全链路医疗健康平台的核心 AI 服务，等待与 Java 后端真实连通。

**技术栈**: FastAPI + LangGraph + MCP（来源：系分 §2）

**四层架构**（来源：系分 §4.2）：

| 层 | 目录 | 职责 |
|----|------|------|
| 接入层 | `app/api/` | 对话端点 + JWT 鉴权 + 限流 + traceId |
| 编排层 | `app/orchestrator/` | LangGraph 主图 + 业务子图 + 节点（只调度不实现） |
| 引擎层 | `app/engine/` + `app/mcp_server/` + `app/mcp_client/` | LLM 工厂 + 工具 Schema + RAG + MCP 工具封装 |
| 基础设施层 | `app/infrastructure/` | Java 客户端 + Redis + 配置 + 审计（零业务依赖） |

**核心机制**（来源：系分 §5）：

- 对话流程：前端 JWT → 鉴权 → 意图识别 → [业务子图/RAG] → 回复生成 → SSE 流式
- L1-L4 安全：L1 直接执行 / L2 confirm_token 确认卡 / L3-L4 不注册（双层代码防线，prompt 禁令仅辅助）
- SSE 事件：`message` / `thought` / `action` / `observation` / `card` / `done` / `error`（契约见系分 §6.2.1）

**核心边界**（来源：系分 §3 场景定义）：

| 原则 | 含义 |
|------|------|
| 能查不能断 | 可查报告/药典，不可确诊、不可开方 |
| 能建议不能决定 | 可推荐医生/药品，不可替人挂号、替人下单 |
| 能代办不能代确认 | 可发起流程、创建草稿，但敏感操作必须人工确认 |
