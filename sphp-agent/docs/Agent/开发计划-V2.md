## 一、项目概述

**智愈先锋(SPHP) Agent 模块** — AI 驱动的全链路医疗健康平台的核心 AI 服务。

### 技术栈

FastAPI + LangGraph + MCP（Model Context Protocol）

### 四层架构

```
① API 接入层 (app/api/)         - 对话端点 + JWT 鉴权 + 限流
② 编排层 (app/orchestrator/)    - LangGraph 主图 + 子图 + 节点函数
③ 引擎层 (app/engine/)          - LLM 工厂 + 工具 Schema + RAG
④ MCP Server (app/mcp_server/)  - 工具封装（stdio transport）
⑤ 基础设施层 (app/infrastructure/) - Java 客户端 + Redis + 配置
```

### 核心机制

- **对话流程**: 前端 JWT → 鉴权 → 意图识别 → [业务操作/医疗咨询] → [工具调用/RAG] → 回复生成 → SSE 流式
- **L1-L4 安全**: L1 直接执行 / L2 生成 confirm_token 等待确认 / L3-L4 代码硬拦截不注册
- **SSE 事件**: `message`（LLM 输出）/ `thought`（推理 token）/ `action`（工具开始）/ `observation`（工具结果）/ `card`（L2 确认）/ `done`（完成，含 token 用量）

### 核心边界

| 原则 | 含义 |
|------|------|
| 能查不能断 | 可查报告/药典，不可确诊、不可开方 |
| 能建议不能决定 | 可推荐医生/药品，不可替人挂号、替人下单 |
| 能代办不能代确认 | 可发起流程、创建草稿，但敏感操作必须人工确认 |

### M3：L2 确认可用 ✅

**目标**: 创建型操作走 card 确认 → confirm 回调 → 执行 → 返回结果。全链路（含 E2E）已跑通。

**关键交付**
- Redis confirm_token 原子消费：Lua SCAN 前缀匹配 + user_id 校验 + 一次性 GET+DEL（key 格式 `confirm:{session}:{tool}:{token}` 不变）

- 测试：`test_chat_confirm.py` 7 用例 + `test_safety.py` 6 用例 + E2E L2 确认全链路（token 一次性，重复提交过期）

### 部署要点

**启动依赖链**: PostgreSQL(5432) → Java(8080) → Agent(8081) → 前端(8000/8001)。Agent 不内嵌 Java，通过 `JAVA_BASE_URL` 调用；与 Java 共用同一套 PG/Redis。

**pgvector 扩展**: 目标 PG 必须执行 `CREATE EXTENSION vector`（向量库首次建表依赖），否则启动报错。

**生产部署**（`DEBUG=False` 必须关闭 reload）:
```bash
nohup .venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8081 > agent.log 2>&1 &
```
推荐 systemd 托管（开机自启 + `Restart=always`），`EnvironmentFile` 指向 `.env`。

**常见问题**: 端口用 `AGENT_HOST/AGENT_PORT`（非旧 HOST/PORT）；MCP 未启用则 `pip install mcp`；连不上 PG 核对 `PG_*`。
