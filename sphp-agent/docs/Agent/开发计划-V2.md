## 二、当前进度（2026-08-02 更新）

### 2.1 已完成的核心修改（P0优先级）

#### ✅ 1. JWT 鉴权节点 (auth_node)

**文件**: `app/orchestrator/nodes/auth.py`

**修改内容**:
- ✅ 实现真实的JWT鉴权逻辑
- ✅ 调用Java token/parse接口获取用户信息
- ✅ 支持C端和B端场景
- ✅ B端场景自动注入 roles/dept_id/doctor_id/hospital_id
- ✅ 定义 AgentAuthError 异常类
- ✅ 完整的异常处理和日志记录

**关键代码**:
```python
user_info = await parse_token(jwt_token, scope)
result = {
    "user_id": user_info.get("userId"),
    "account": user_info.get("account"),
}
if scope == "b_end":
    result.update({
        "roles": user_info.get("roles", []),
        "dept_id": user_info.get("deptId"),
        "doctor_id": user_info.get("doctorId"),
        "hospital_id": user_info.get("hospitalId"),
    })
```
