# 发烧的处理建议

> 演示样例数据，非真实医疗内容。实际部署请替换为权威机构发布的科普文档。

## 什么是发烧

发烧是指体温升高超过正常范围。通常腋下温度达到 37.3℃ 以上可视为发热。体温在 37.3℃—38℃ 为低热，38.1℃—39℃ 为中热，39℃ 以上为高热。发热本身不是疾病，而是身体对抗感染的一种防御反应。

## 家庭物理降温

低热且精神状态尚可时，可先采用物理方式缓解不适：多饮温水补充流失水分；用温水擦拭额头、颈部、腋下和腹股沟帮助散热；保持室内通风、穿着轻薄衣物。不建议用酒精擦浴或冰水冷敷，以免引起寒战或皮肤刺激。

## 何时需要及时就医

出现以下情况应尽快就诊：体温超过 39℃ 持续不退；发热超过 3 天；伴随剧烈头痛、持续呕吐、呼吸困难、皮疹、意识模糊或抽搐；婴幼儿发热超过 38.5℃；慢性病患者发热。这些可能提示需要进一步检查明确病因。

## 常见误区

发热时不要过度包裹捂汗，反而不利散热。自行使用退烧药应遵药品说明书，避免多种含相同成分的感冒药叠加服用。退烧药只缓解症状，不治疗病因，反复发热应就医明确原因。
