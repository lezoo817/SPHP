# 高血压日常管理

> 演示样例数据，非真实医疗内容。实际部署请替换为权威机构发布的科普文档。

## 认识高血压

高血压是指在未使用降压药的情况下，非同日三次测量收缩压≥140mmHg 和/或舒张压≥90mmHg。高血压早期常无明显症状，但长期控制不良会损害心、脑、肾等重要器官，因此被称为"无声杀手"。

## 饮食与生活方式

日常管理是控制血压的基础。建议限制食盐摄入，每日不超过 5 克；多吃新鲜蔬菜水果、全谷物，减少腌制和加工食品；戒烟限酒；保持规律的有氧运动如快走、游泳，每周 5 次以上、每次 30 分钟；控制体重在正常范围；保持规律作息，避免长期熬夜和精神紧张。

## 规律监测与服药

确诊高血压后应定期测量血压并记录。服用降压药需遵医嘱按时按量，不可自行停药或增减剂量，即使血压正常也应继续维持治疗。切忌凭感觉吃药或听信偏方替代正规药物。

## 何时需要就诊

血压持续升高或波动较大时应就医调整方案。出现剧烈头痛、胸痛、视物模糊、肢体无力、言语不清等情况，可能提示高血压急症，应立即就医。
