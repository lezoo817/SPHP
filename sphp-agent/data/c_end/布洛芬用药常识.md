# 布洛芬用药常识

## 布洛芬的用途

布洛芬属于非甾体抗炎药，具有退热、止痛、抗炎作用。常用于缓解轻至中度疼痛如头痛、牙痛、肌肉痛、痛经，以及感冒引起的发热。

## 用法用量

成人退热或止痛一般每次 200—400mg，间隔 4—6 小时可重复，24 小时不超过 4 次。建议饭后服用以减少胃肠刺激。儿童需使用儿童剂型并按体重计算剂量，不建议成人剂型直接给儿童使用。

## 注意事项与禁忌

布洛芬常见不良反应为胃肠道不适，长期或大量使用可能损伤胃黏膜、影响肾功能。有消化性溃疡、严重肝肾功不全、哮喘、对阿司匹林过敏者慎用或禁用。服药期间不要饮酒，避免与其他非甾体抗炎药或含相同成分的复方感冒药同服，防止剂量叠加。

## 何时需要就医

自行服药用于缓解症状一般不超过 3—5 天。若发热持续超过 3 天、疼痛加重或出现黑便、皮疹、呼吸困难等异常反应，应停止用药并就医。孕妇及哺乳期妇女使用前应咨询医生。
