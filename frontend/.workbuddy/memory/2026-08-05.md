### 关键设计决策
1. **类型用 declare global namespace Agent**：与现有 API namespace 一致，全局可见无需 import
2. **token 续期**：B 端无 refreshToken 逻辑，401 直接清 b_access_token 跳登录（与 app.ts/login 一致）
3. **会话策略**：遵循系分§5.9，consultationId 变化时 reset()，一次问诊一个会话
4. **Antd 5.x 适配**：用 Card/Collapse/Descriptions/Drawer/Tag 等，不依赖 lucide-react（C 端用）
5. **双形态 AiPanel**：embedded 接诊台侧栏 + 全屏独立页，共用 useAgentStream
