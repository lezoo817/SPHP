### 关键实现点
- SSE 解析：用 ReadableStream + TextDecoder 按 `\n\n` 切帧，解析 `event:`/`data:`
- 工具卡片配对：action 建 loading 卡片，observation 从后往前匹配同 tool 的 loading 卡片更新；未匹配则新建已完成卡片
- observation.status 归一化：后端字段为 `success` 布尔，前端转 `success`/`error`
- 确认卡片状态机：pending→confirming→done/error/expired；过期/已消费/无效时置灰禁用
- 鉴权：401 时清理登录态跳登录；复用现有 sessionStorage 会话模型
- 对话上下文：从路由路径推导 page，从 selection 模型取 hospital_id/patient_id
