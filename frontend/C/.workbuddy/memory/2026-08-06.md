## C 端 H5 —— 确认卡片成功后追加 AI 消息

按需求：confirm() 成功分支只在卡片内部更新 resultMessage 不够醒目，
用户可能以为"没下文"。需在卡片 done 之后追加一条 assistant 消息到对话流。

### 改动
- `src/hooks/useAgentStream.ts` —— confirm() 成功分支 updateConfirmCard 之后，
  setEntries 追加一条 `{kind:'message', data:{role:'assistant', content: result.message}}`
- **不走 send()**：send 会触发新 chatStream 请求且 streaming 时被拦截；
  直接 setEntries 追加纯文本，不发起请求、不消耗会话
- 失败分支不变（catch 只更新卡片 error 态，不追加消息）

### 数据契约
- confirmCard 返回 `Promise<AgentConfirmData>`，code === '00000' 时
  `data = { action_result?, message? }`，message 由后端按工具返回友好文案
  （save_pre_consultation → "预问诊已提交给医生" 等）
